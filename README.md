# 💻 Software Engineer Portfolio

A modern personal portfolio built with React and Vite to showcase my software engineering projects, technical skills, and experience.

## 🚀 Technologies

- React
- JavaScript
- CSS
- Vite
- Git & GitHub

## ✨ Features

- Responsive single-page portfolio
- Modern UI with a dark theme
- Featured projects with media previews
- Skills section with technology badges
- About section
- Contact section
- GitHub, LinkedIn and itch.io links

## 📂 Projects Featured

- Portfolio Website
- CyberX: Race
- Dino Task Manager
- Tank World

## 🛠️ Running Locally

Clone the repository:

```bash
git clone https://github.com/Sami-Red/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
